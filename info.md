# Leaf It Alone 3D - Game Information

## The Vision
"Leaf It Alone 3D" is an addictive, hyper-casual idle-progression game built natively for the web using React Three Fiber. Set in a beautiful, low-poly 3D garden, players are tasked with the deeply satisfying job of cleaning up fallen leaves.

## Core Loop
1. **Collect**: Players click on 3D leaves scattered around the garden to collect them into their bag.
2. **Deposit**: Once the bag is full, the player clicks the Compost Bin to empty the bag and earn Coins.
3. **Upgrade**: Players spend Coins in the Upgrade Shop to improve their leaf-picking efficiency (Picking Power) and their bag size (Bag Capacity).
4. **Scale**: The game scales from clicking a single leaf at a time to vacuuming up dozens of leaves per click, providing a satisfying sense of progression.

## Platform Target
This game is specifically architected for deployment on **CrazyGames**. It features:
- Fast load times (HTML5/React native).
- Embedded CrazyGames SDK for monetization (Rewarded Ads for Coin Boosts).
- Fully responsive UI for both Desktop and Mobile players.
